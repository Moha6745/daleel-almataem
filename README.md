# دليل المطاعم

دليل لمطاعم الرياض يعرض المنيو والتقييمات، ويقارن أسعار الطلب بين تطبيقات التوصيل
(**جاهز**، **هنقرستيشن**، **كيتا**) ليحدّد الأوفر لكل طلب.

موقع ثابت بدون أي اعتماديات — HTML و CSS و JavaScript فقط. حالياً **٤٩ مطعم**.

## المميزات

- تصفّح المطاعم مع فلترة حسب نوع الطعام
- بحث بالاسم أو الحي أو اسم الفرع أو نوع الأكل، وترتيب حسب التقييم أو السعر أو عدد التقييمات
- صفحة لكل مطعم: قائمة الطعام، مقارنة التطبيقات، التقييمات وآراء الزوار
- **الفرع مثبّت لكل مطعم**: المطاعم لها فروع كثيرة وتقييمها يختلف من فرع لفرع، فكل مطعم
  مربوط بفرع واحد محدّد مع رابط مباشر لصفحته في قوقل ماب
- سعر كل صنف معروض داخل كل تطبيق، والأرخص مظلّل
- **مقارنة على مستوى الطلب**: تحدّد الأصناف اللي تبي تطلبها فتُحسب التوصية على سلتك أنت لا على المنيو كامل — لأن التطبيق الأوفر يتغيّر حسب محتوى الطلب ورسوم التوصيل
- إضافة تقييم من داخل الصفحة (يبقى في جلسة المتصفح فقط)

## من وين تجي البيانات؟ (اقرأ هذا أولاً)

**الموقع حالياً فيه بيانات تجريبية.** الأسعار والتقييمات المكتوبة في `data.js`
**ما جُمعت من أي مصدر حقيقي** — هي أرقام مبدئية كُتبت لعرض شكل الموقع فقط.
الواجهة تعلّم كل مطعم غير متحقَّق منه بوضوح عشان ما يلتبس على أحد.

| البيان | المصدر | كيف يصير حقيقياً |
|---|---|---|
| أسماء المطاعم والأحياء والفروع | مُدخلة يدوياً | `discover-restaurants.mjs` يجيبها من قوقل ماب |
| التقييم وعدد التقييمات | **تجريبي** | `fetch-google-ratings.mjs` |
| المنيو والأسعار | **تجريبي** | `import-from-images.mjs` |
| رسوم التوصيل ونسب زيادة التطبيقات | **تجريبي** | `import-from-images.mjs` |
| الآراء المكتوبة | **نصوص كتبها الذكاء الاصطناعي** | تحتاج قاعدة بيانات ومستخدمين حقيقيين |

في `data.js` علمان يتحكمان بالعرض:

| العلم | معناه | من يرفعه |
|---|---|---|
| `verified: true` | الأسعار اتجمعت فعلاً | `import-from-images.mjs` |
| `ratingVerified: true` | التقييم من قوقل ماب | `fetch-google-ratings.mjs` |

بدون العلمين، الواجهة تعرض تحذير «بيانات تجريبية» على البطاقة وداخل الصفحة.

### ليش الأسعار ما تُسحب آلياً من التطبيقات؟

**جاهز وهنقرستيشن وكيتا ما عندهم واجهة بيانات عامة.** الوصول لمنيوهم وأسعارهم
يحتاج توكن دخول من داخل التطبيق ويخالف شروط استخدامهم. لهذا ما فيه سكربت يسحب
منهم، وبدلاً منه فيه مسار الصور تحت — أنت تصوّر شاشتك، والسكربت يقرأ الصور.

## الأدوات

```bash
npm install     # مرة وحدة — الاعتماديات لأدوات tools/ فقط، الموقع نفسه بدون اعتماديات
```

### ١. اكتشاف مطاعم حقيقية من قوقل ماب

```bash
export GOOGLE_MAPS_API_KEY="مفتاحك"

node tools/discover-restaurants.mjs --dry --cuisine=برغر
node tools/discover-restaurants.mjs --cuisine=برغر --max=40
node tools/discover-restaurants.mjs --all --max=30
node tools/discover-restaurants.mjs --query="مطاعم مندي في الرياض" --cuisine=سعودي
```

يبحث داخل حدود الرياض ويضيف الجديد فقط (يتجاهل الموجود). اللي يجي حقيقي:
الاسم والحي والعنوان والتقييم وعدد التقييمات ومستوى السعر. الناقص: المنيو والأسعار.

### ٢. تعبئة المنيو والأسعار من صور المنيو

الطريقة العملية: تفتح منيو المطعم داخل كل تطبيق على جوالك وتصوّر لقطة شاشة.
ما فيه أي اتصال بسيرفرات التطبيقات — الصور من شاشتك أنت.

```bash
# menu-images/albaik-jahez.png  ·  albaik-keeta.png  ·  albaik-branch.png
export ANTHROPIC_API_KEY="sk-ant-..."

node tools/import-from-images.mjs --dry
node tools/import-from-images.mjs
node tools/import-from-images.mjs --only=albaik --effort=high
```

يقرأ الصور، يطابق نفس الصنف عبر التطبيقات، يحسب نسبة زيادة كل تطبيق، ويرفع
علم `verified`. راجع [`menu-images/README.md`](menu-images/README.md) لتسمية الصور.
التكلفة ≈ **٤ سنتات لكل مطعم** على Claude API.

> **ما تحتاج تعبّي كل صنف في كل تطبيق.** لكل صنف سعر أساس واحد (`base`)، ولكل
> تطبيق نسبة زيادة واحدة (`mult`) تغطي المنيو كامل. صورة من كل تطبيق تكفي.

### ٣. تحديث التقييمات من قوقل ماب

```bash
export GOOGLE_MAPS_API_KEY="مفتاحك"

node tools/fetch-google-ratings.mjs --dry
node tools/fetch-google-ratings.mjs
node tools/fetch-google-ratings.mjs --only=albaik,kudu
```

يبحث عن كل مطعم بـ `الاسم + الفرع + الرياض`، ويكتب التقييم الحقيقي ويرفع علم
`ratingVerified`.

### المفاتيح

- **Google Maps** (للأداتين ١ و٣): [console.cloud.google.com](https://console.cloud.google.com)
  → فعّل **Places API (New)** → أنشئ API key. مدفوع حسب تسعيرة قوقل.
- **Anthropic** (للأداة ٢): [console.anthropic.com](https://console.anthropic.com) → API Keys.

لا تحط المفاتيح في الملفات — استخدم `export` أو GitHub Secrets.

## التشغيل محلياً

```bash
git clone https://github.com/<اسم-حسابك>/daleel-almataem.git
cd daleel-almataem
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

> افتح الموقع عبر خادم محلي وليس بفتح `index.html` مباشرة، لأن المتصفح يمنع تحميل
> ملفات `.js` من مسار `file://` في بعض الإعدادات.

## تعديل البيانات

كل مطعم كائن واحد في `data.js`:

```js
{
  id:"section-b", name:"سكشن بي", cuisine:"برغر", district:"العليا",
  branch:"فرع طريق العروبة", verified:true, ratingVerified:true,
  rating:4.5, reviewsCount:2140, price:"$$", eta:"30–40 د",
  about:"وصف قصير للمطعم.",
  apps:{
    jahez:  {on:true,  mult:1.10, fee:9},
    hunger: {on:true,  mult:1.15, fee:12},
    keeta:  {on:true,  mult:1.06, fee:5}
  },
  menu:[
    {n:"سكشن برغر لحم", d:"وصف الصنف", base:38}
  ],
  reviews:[
    {who:"عبدالله ا.", r:5, dt:"قبل ٣ أيام", t:"نص التقييم."}
  ]
}
```

| الحقل | المعنى |
|---|---|
| `district` | الحي |
| `branch` | الفرع اللي أُخذ منه التقييم (يُبنى منه رابط قوقل ماب تلقائياً) |
| `rating` / `reviewsCount` | تقييم الفرع |
| `verified` | الأسعار اتجمعت فعلاً (بدونه تظهر تحذيرات في الواجهة) |
| `ratingVerified` | التقييم من قوقل ماب |
| `base` | سعر الصنف في الفرع بالريال |
| `mult` | معامل زيادة التطبيق على سعر الفرع (`1.10` = زيادة ١٠٪) |
| `fee` | رسوم التوصيل بالريال (`0` = توصيل مجاني) |
| `on` | هل المطعم متاح على هذا التطبيق |

السعر داخل التطبيق = `base × mult`، وإجمالي الطلب = مجموع الأصناف + `fee`.
لتعديل أسعار مطعم كامل يكفي تغيير `mult` و `fee`.

أنواع الطعام المتاحة: `برغر` `بيتزا` `سعودي` `شاورما` `دجاج` `مشاوي` `أمريكي`
`آسيوي` `معجنات` `قهوة وحلا` — لإضافة نوع جديد أضفه إلى `CUISINES` و
`CUISINE_EMOJI` و `CUISINE_BG` في نفس الملف.

## النشر على GitHub Pages

فعّله مرة واحدة من: **Settings → Pages → Source → GitHub Actions**.

## ملاحظات مهمة

- **البيانات الحالية تجريبية** ولا تصلح لاتخاذ قرار طلب — راجع جدول المصادر فوق.
- أسعار تطبيقات التوصيل تتغير يومياً، فحتى الأسعار المستوردة تحتاج تحديث دوري.
- المقارنة لا تحتسب كوبونات الخصم ولا اشتراكات التوصيل المجاني، وهذه غالباً تقلب النتيجة.
- التقييمات المضافة من الواجهة لا تُحفظ — تحتاج قاعدة بيانات لذلك.
- `menu-images/` مستثناة من git: الصور تبقى على جهازك.
- المشروع مستقل وغير تابع لأي تطبيق توصيل، ولا يستخدم شعاراتهم أو علاماتهم التجارية.
